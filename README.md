# Cartão de visitas — GitHub Pages

Este diretório contém a versão estática pronta para publicação.

## Personalização rápida

- Edite nome, descrição e textos em `index.html`.
- Os links fictícios estão no array `profiles`, no fim de `index.html`.
- Para trocar a foto, substitua `heraldo.jpg` mantendo o mesmo nome.

## Publicação

Copie estes três arquivos para a raiz do seu repositório, envie-os ao GitHub e, em **Settings → Pages**, selecione a branch principal e a pasta raiz.
